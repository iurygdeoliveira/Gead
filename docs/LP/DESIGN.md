# 🎨 GeAD Design System
**Creative North Star:** O Painel Ágil

## 1. Brand Personality & Voice
Uma interface projetada para não atrapalhar. Leve, respirável e imediata, rejeitando padrões burocráticos densos. As informações primárias saltam à vista sem exigir do usuário uma curva de aprendizado.

## 2. Core Tokens

### 2.1 Colors
- **Primary (Verde-Limão Acelerado):** `oklch(0.931 0.228 123.104)`
- **Gray (Neutral):** `oklch(0.583 0.005 179.618)`
- **Success:** `oklch(0.723 0.219 149.579)`
- **Warning:** `oklch(0.769 0.188 70.08)`
- **Danger:** `oklch(0.583 0.239 28.584)`
- **Info:** `oklch(0.623 0.214 259.815)`

### 2.2 Typography
- **Primary Font:** Poppins
- **Fallback:** Inter Variable, sans-serif

**Hierarchy:**
- **Heading 1:** 32px / 38px (Font weight: 700, Letter spacing: -0.02em)
- **Heading 2:** 28px / 35px (Font weight: 600, Letter spacing: -0.02em)
- **Heading 3:** 20px / 28px (Font weight: 600)
- **Heading 4:** 17.6px / 24px (Font weight: 600, Letter spacing: -0.01em)
- **Body / Regular M:** 14px / 20px (Font weight: 400)
- **Bold M:** 14px / 20px (Font weight: 700)
- **Label:** 14px / 20px (Font weight: 700)
- **Small (Regular S):** 12px / 16px (Font weight: 400)
- **Small Bold (Bold S):** 12px / 16px (Font weight: 700)
- **Monospace:** 13px / 20px

### 2.3 Radii & Spacing
- **Radius (Cards/Components):** `1rem`
- **Spacing:** Base is `0.5rem`, using standard Tailwind scaling.

## 3. UI Philosophy

### 3.1 Elevation
**Flat-by-default:** O sistema é plano. Usamos tons de fundo e bordas sutis para separar áreas. Sombras aparecem apenas quando algo "levanta" (hover, modais, tooltips).

### 3.2 Components
**Arredondados, táteis e acessíveis:** Foco no clique fácil no celular, bordas arredondadas e amigáveis, priorizando o toque rápido sem frustração.
